# Deployment Instructions for GitHub Pages

## Automatic Deployment (Recommended)

This site is configured for automatic deployment via GitHub Actions.

### Setup Steps:

1. **Create GitHub Repository**
   ```bash
   # On GitHub.com, create a new repository: faridrameli/tools-site
   # Make it public (required for free GitHub Pages)
   ```

2. **Add Remote and Push**
   ```bash
   cd C:\Users\User\Documents\GitHub\autobots-lab\tools-site
   git remote add origin https://github.com/faridrameli/tools-site.git
   git push -u origin master
   ```

3. **Enable GitHub Pages**
   - Go to repository Settings → Pages
   - Source: "GitHub Actions"
   - The workflow will automatically deploy on every push to master

4. **Site URL**
   - Will be available at: https://faridrameli.github.io/tools-site/
   - Or custom domain if configured

## Manual Deployment (Alternative)

If GitHub Actions is not preferred:

```bash
# Build the site
npm run build

# Deploy using gh-pages branch
git checkout --orphan gh-pages
git rm -rf .
cp -r out/* .
git add .
git commit -m "Deploy to GitHub Pages"
git push -f origin gh-pages

# Then enable GitHub Pages in repo settings:
# Settings → Pages → Source: Deploy from branch → Branch: gh-pages → / (root)
```

## Files Included

- `.github/workflows/deploy.yml` - GitHub Actions workflow for automatic deployment
- `out/` - Built static files (generated by `npm run build`)
- `.nojekyll` - Ensures GitHub Pages serves all files correctly
